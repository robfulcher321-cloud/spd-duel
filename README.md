# SPD Duel

A 1v1 PvP mod of [Shattered Pixel Dungeon](https://github.com/00-Evan/shattered-pixel-dungeon) by Evan Debenham (based on Pixel Dungeon by Watabou). Licensed under GPLv3, like the original.

Installs as a separate app ("SPD Duel") alongside the official game.

**Download:** see the `latest` release on this repo for `SPD-Duel.apk`.

Work in progress.

## Updating

From build 16 onward, the app checks for new builds when it opens and can update itself from inside the game ("Update now").
